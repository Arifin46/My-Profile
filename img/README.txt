Put your profile photo in this folder as:

    profile.jpg

It will appear automatically in the avatar circle on index.html.
Recommended: a square image, at least 400x400px.

If the file is missing, the site shows the "AA" initials instead,
so the page never looks broken.

To use a different format, edit index.html and change:
    src="img/profile.jpg"
to e.g.
    src="img/profile.png"
