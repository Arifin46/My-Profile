My story

My journey started with C in my first semester. Printing a pyramid of stars felt like magic, so I kept going: C++, then Java for object-oriented thinking, then Python for scripting and quickly building ideas.

When I reached web technology, everything clicked. HTML and CSS let me see my work instantly, JavaScript made it interactive, and PHP with Laravel finally gave me the structure to build complete applications — routing, models, controllers and Blade views.
